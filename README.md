# How to get environtment Variables
Go to [OUR TELEGRAM CHANNEL](https://t.me/alyxcli)
Copy the provided environment variables and paste it into a text file named `.env` in the same directory as `main.py`.
You can use nano or any text editor to create the file.

# How to run on Linux
1. Install prerequisites
Debian/Ubuntu:
```
sudo apt update && sudo apt install -y git python3 python3-pip python3-venv python3-pillow
```
Fedora:
```
sudo dnf install -y git python3 python3-pip python3-pillow
```
Arch:
```
sudo pacman -S --noconfirm git python python-pip python-pillow
```
2. Clone this repo
```
git clone https://github.com/purplemashu/me-cli-sunset
```
3. Open the folder
```
cd me-cli-sunset
```
4. Setup (creates a virtualenv and installs dependencies)
```
bash setup.sh
```
5. Run the script
```
source venv/bin/activate
python main.py
```
